# 🥑 7 Kunlik Parhez — Mobil Web Ilova

84 kg dan 74 kg gacha (−10 kg) sog‘lom ozish uchun 7 kunlik mukammal taomnoma, kunlik ptichka qo‘yish, 2.5L suv hisoblagichi va vazn monitoringi dasturi.

## 🚀 Imkoniyatlar
- 📅 **Kunlik Menyu:** Nonushta, Tushlik, Gazak va Kechki ovqat taomlariga ptichka qo‘yish.
- 💧 **Suv Hisoblagich:** Kunlik 2.5 litr (10 ta stakan × 250 ml) suv nazorati.
- 👟 **Kunlik Odatlar:** 10 000 qadam, shakarsiz kun, kechki ovqat vaqti, mashq va uyqu cheklisti.
- 🛒 **Bozorlik Ro‘yxati:** Mahsulotlar toifalari bo‘yicha interaktiv xarid ro‘yxati.
- ⚖️ **Vazn & BMI:** Haftalik vazn o‘zgarishi tarixi va maqsad kalkulyatori.
- 💾 **Doimiy Saqlash (`localStorage`):** Barcha ptichkalar brauzer/telefon xotirasida saqlanadi.
- 📱 **Mobil Moslashuvchanlik (PWA):** iOS va Android ekranlariga to‘liq moslashtirilgan.

## 📦 Ishga tushirish (Local)
```bash
python3 server.py
```
yoki brauzerda `index.html` faylini oching.
